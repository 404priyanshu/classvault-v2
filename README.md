# ClassVault v2

> **Earlier ClassVault iteration.** For the current project and live product, see [ClassVault](https://github.com/404priyanshu/classvault).

This repository preserves an earlier Next.js, React, and TypeScript implementation with Supabase client libraries. It is kept as a development reference; the current ClassVault repository is the starting point for the product.

## Local development

This version uses pnpm. Review its source and environment requirements before running it.

```bash
pnpm install
pnpm dev
```

Available checks: `pnpm lint`, `pnpm typecheck`, and `pnpm build`.
